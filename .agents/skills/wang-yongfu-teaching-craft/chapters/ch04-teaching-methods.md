# 第 4 章：一定要會用的各種教學法（教學的技術）

## Core Idea
教學法是工具箱：講述、問答、小組討論、演練（PESOS）、三明治回饋、影片、個案討論——依「知識／技巧／態度」目標與現場溫度混合使用，不斷轉換。

## Frameworks Introduced
- **講述法的成立條件**：講者修練（內容紮實＋表達生動）×聽眾意願（動機強則怎麼教都學）——兩者皆弱時，講述是最差的選項
- **問答法操作四技巧**：
  1. 開始時主動 Cue 人（眼神善良者先），沒意願立刻換人
  2. 摘要重述學生回答（鏡像技巧：讓他感到被聽見、讓全場聽得到）
  3. 讚美而不批評——任何批評都會讓之後的回答全部噤聲
  4. 最後提出老師的想法或洞見（把想說的話透過問答讓學生說出口）
  - 注意：題目經設計（問答題較簡單、討論題較難）；搭配獎勵機制；不要只用問答法（小火花很快降溫）
- **小組討論法**：流程＝老師出題 → 學員討論 → 學員發表 → 老師總結。四個眉角：
  1. 題目清楚秀在投影片上、聚焦單一問題
  2. 結論寫在大張壁報紙（沒寫紙的討論只是「小組聊天」）
  3. 時間抓緊（音樂＋倒數塑造壓力）
  4. 出題時預告「等一下邀請大家發表」，不先說只請一組
- **演練法五步驟 PESOS**：Preparation 學習前準備 → Explanation 我說給你聽 → Show 我做給你看 → Operation 讓你做做看 → Supervise 成效追蹤（指導）
  - 三個提醒：①先示範才練習（複雜動作分段示範或預錄影片）②提供流程範例當鷹架但與演練題有差異（無法照抄）③不要邊演練邊打斷——忍到告一段落再回饋
- **三明治回饋法**：優點（肯定具體表現）→ 改進（下次可以更好的地方）→ 優點（整體激勵＋掌聲）。目的：回饋是過程，進步才是結果
- **影片教學法**：三用途（觀察討論素材／教學示範／感性結尾）＋三提醒（3–5 分鐘內、內嵌投影片自動播放且先測試、影片是輔助教學不是重點）
- **個案討論法三關鍵**：①模擬真實情境（改編人名公司名、短而濃縮能入戲）②討論本身就是學習——老師忍住不說，用提問引導（即使有人答對也追問缺點）③收斂重點＋公布真實世界後續（討論與真相的落差正是最佳學習點）

## Key Concepts
- **「聽懂 vs. 會做」是兩回事**：技巧類教學（ASK 中的 S）必用演練驗收
- **老師說得越少，學生學得越好**：小組討論把學習的球丟給學員——講述法教得快忘得快，討論法教得慢記得多
- **成人學員不是白紙**：多數基本問題已有基礎，掙扎後再聽補充才會「豁然貫通」
- **知識轉換率**（MJ 老師用語）：講者想講的與聽眾記得的比值，是教學品質的度量

## Mental Models
- 把問答法當「破冰小火花」、小組討論當「主引擎」、演練當「驗收關」——層層遞進
- 回饋像三明治：沒有糖衣的苦藥（只講缺點）吞不下去；只有麵包（只講優點）沒有營養

## Anti-patterns
- **回饋三錯**：跳過優點只講缺點（學員不改）、只講優點無改善點（等於沒講）、用「但是」連接（一個字抹煞前面讚美——改用「如果可以的話」「下一次有機會」）
- **演很多、練很少**：只說明不示範就要求演練
- **邊演練邊打斷指正**：讓學員完成一次再回饋
- **影片變電影欣賞會**：播放前沒提示觀察重點、超過十分鐘、現場未測試
- **個案討論先破梗**：忍不住公布答案，謀殺思考過程

## Worked Example
90 秒電梯簡報的三明治回饋實例：
1. 優點：「Simon 大部分內容都記住了，能在 90 秒內濃縮完整簡報，壓力下仍堅持講完，很棒。」
2. 改進：「一開始沒談到簡報大結構；第二段有些忘詞；與台下目光接觸較少——這些是下次可以更好的地方。」
3. 優點：「整體來看能在短時間記住內容並完整呈現，看得出真的很努力！請給他掌聲鼓勵！」

## Key Takeaways
1. 教學法沒有好壞，只有效果——依主題、對象、時段混合變換
2. PESOS 五步驟缺一不可，「我做給你看」最常被跳過
3. 小組討論是企業內訓的核心武器：翻轉單向關係
4. 三明治回饋＋避開「但是」，回饋才會帶來改變
5. 個案討論的重點是過程中的思考，不是答案對錯
