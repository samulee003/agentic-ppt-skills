# 第 2 章：課程的分析、設計與發展（教學的技術）

## Core Idea
好課程是系統化規劃出來的，不是從做投影片開始。用 ADDIE 五步驟走完分析→設計→發展，其中「可被評估的教學目標」是一切的核心。

## Frameworks Introduced
- **ADDIE 系統化課程設計五步驟**
  - Analysis 分析：學員是誰？痛點？目標？（最重要：學員、時間、教學目標三件事）
  - Design 設計：發想資料蒐集 → 流程安排 → 教學法規劃（用便利貼法，不寫文件）
  - Development 發展：投影片（三大手法）＋教學法插入
  - Implementation 執行：課堂授課，「老師說得越少，學生學得越好」
  - Evaluation 評估：不是打分數，而是反映學生想法、回饋到下次課程設計
- **教學目標可評估性檢驗**
  - 無效目標：「提升工作效率」「過著更好的人生」——漂亮但無法在課後立即驗證，誰來教都一樣
  - 有效目標：具體列出三個學習重點＋每項的內容範圍＋課末驗收方式（案例實作、demo case）
- **發想資料三來源**：網路搜尋、別人的投影片（`關鍵字 filetype:ppt`）、多本參考書——記在便利貼而非照抄
- **投影片三大手法**（源自《上台的技術》）：大字流（出題、重點聚焦）、半圖半文字（歸納、演練指示）、全圖像（證據、找碴出題）
- **投影片兩原則**：一頁一重點（投影片不是講義，講義另外做、可留空填答）；講到才出現（逐段顯示控制注意力）

## Key Concepts
- **有靈魂的課程**：內容超出書本與網路，來自知識通達與實務累積——設計階段即見真章
- **直球對決**：流程不鋪理論，開場即用錯誤個案切入，別浪費學員初期注意力
- **便利貼法**：發想→分類→排序→重點分段的課程設計工具
- **杜拉克目標檢視**：設定目標後一段時間比對預期與實際，持續修正

## Mental Models
- 把課程設計想成「分析在前、投影片最後」的瀑布——大部分老師做反了
- 教學投影片的標準是「輔助教學」而非美觀；資訊負載過大或節奏太快都會引發焦慮

## Anti-patterns
- **第一件事就做投影片**：錯誤的開始，跳過了學員需求與目標分析
- **教學目標口號化**：無法評估的目標＝沒有目標
- **投影片當講義**：塞滿文字只有催眠效果
- **不斷開發新課程**：沒有經驗累積；頂尖講師專精一兩門課教到最好

## Worked Example
「時間管理」課程目標對比：
- ❌ 無效版：「提升個人工作效率，讓工作運行順利，公司更有生產力，讓學員過著更好的人生」
- ✅ 有效版：「學到三個重點：①工作次序安排（重要緊急矩陣、時間殺手）②時間管理手法（番茄鐘、黃金時間、GTD、每日待辦五件事）③工具應用（APP、計時器、Time Timer、看板）。課末驗收：學員分析自己一週行程、找出核心工作與黃金時間」

## Key Takeaways
1. 先目標、後流程、最後才是投影片
2. 目標必須課後可立即評估，並同步規劃驗收活動
3. 便利貼＋三種資料來源刺激發想，借用 idea 而非複製內容
4. 大字流／半圖半文字／全圖像＋講到才出現，是教學投影片的足夠工具集
5. 發展好課需要時間累積——寧可深耕一門課
