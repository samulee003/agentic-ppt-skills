# 第 11 章：PBL 元素、競爭與回饋——動機的科學（遊戲化教學的技術）

## Core Idea
外在動機（點數、獎勵、排行榜）與內在動機不是對立，而是相輔：外在提升參與的「數量」、內在提升參與的「質量」——用外在當火種點燃內在，並以自我決定論（SDT）三原則完成轉換。

## Frameworks Introduced
- **動機研究結論鏈**：
  - 1971 Deci／1973 Lepper「過度辯證效應／破壞效應」：獎品降低畫畫興趣——遊戲化有害論的源頭
  - 2014 Cerasoli 等綜述（40 年、183 份資料、21 萬人）：外在與內在動機同樣重要、不應二分——「是時候超越破壞效應的研究了」
  - 實務經驗：外在動機先啟動參與→學得好→滋生內在動機（火種理論）
- **P 點數三重點**：
  1. 計分時機：連結課程重點（會出現在考題的觀念）＋預期行為（主動回答、自願上台）
  2. 計分級距：「代幣經濟」——單位只是計算用（1000 分＝1 美元＝300 台幣），一致且好算即可
  3. 計分方式：口頭＋組長記錄／實體籌碼（1000／5000／10000 幣值）／黑板正字——方便、即時、感受好
  - 鐵則：**分數只加不扣**——表現不佳就獎勵其他組（手機響→他組各加 5000）
- **B 獎勵**：「學生想要的，才是好獎勵」
  - 有形：書、疊疊樂、七巧板、簽名書、特產、鼠肺（醫學院！）、Token Shop 代幣換禮物
  - 無形：分數連結學期成績（前三名 All Pass／免一次報告）、與講師合照
  - **負增強**（移除不想要的）：仙女老師「最後一名上台唱四句歌」——青少年不在乎獎品與懲罰，超怕當眾唱歌；第一名免期中報告
  - 三個提醒：①多準備 1–2 份（前三名有獎，避免贏者全拿後落後組放棄）②從一開始就展示獎品並強調特殊性（第三名「全組一個七巧板，每人分到一塊」的幽默話術）③平衡激勵與學習——展示後補一句「上課不是為了獎品，是為了學習，OK 嗎？」
  - 不建議人人有獎：齊頭式公平消除競爭（SDT：獎勵應與表現連結才會內在化）
- **L 排行榜四原則**：
  1. 定時更新「累計總分」（每堂下課由計分員回報；黑板正字／白報紙／便利貼柱狀圖；大場用「5000 以下請坐下」分級起立）
  2. 兼顧競爭與面子：閉眼投票＋只公布前幾名（「從來沒有最後一名」）
  3. 平衡機會：後段高分配比（見 Ch 5 翻盤計算）
  4. 重點激勵：走近落後組微笑施壓「第 2 組有點落後，加油哦！翻盤機會永遠在」——態度輕鬆不指責，不剝奪他組機會
- **SDT 自我決定論應用**（Deci & Ryan 1985）：
  - 自主性：開場宣告「重點是好玩與學習，不是獎品」＋三個承諾——不被強迫感
  - 能力感：直球對決，難度漸增（90 秒電梯簡報、15 分鐘開場稿、20 分鐘記住整份簡報）——「一面哀哀叫，一面相信自己做得到」
  - 連結性：為團隊而戰＋良性競爭——「觀看別人的表現也是學習，請給表現好的夥伴回饋」
- **讓遊戲化失敗的三個方法**（蒙格逆向思考）：①過度強調 PBL（傷自主性——「快拿點數啊！」）②好玩就好不管成長（傷能力感）③贏者為王（傷連結性）；反向的「完全不強調／完全不好玩／完全不競爭」同樣失敗——極端皆死，平衡方活

## Key Concepts
- **分數是二次激勵的基礎**：分數回應當下表現，排行榜顯示累計——兩層激勵
- **閉眼投票**：投的人和被投的人都沒壓力、不受他人影響
- **嘲笑同學？扣 100 分！**（仙女老師）：「肯回答就是有勇氣，答錯加 100；嘲笑別人的那組扣 100（唯一例外）」——但給彌補機會：道歉就不扣——這無關分數，是最好的學習

## Mental Models
- 外在動機＝火種，內在動機＝柴火：點火之後要持續添柴（能力感、連結），火才不滅
- 獎勵像徽章：最後彰顯的是表現與榮譽，獎品本身反而沒那麼重要

## Anti-patterns
- **虛擬徽章**（鑽石學生）——對成人無效
- **隱藏獎品到最後**——失去全程激勵效果
- **一直強調獎勵**（丟果凍給醫師「要咬住哦」）——不尊重學員，重點錯置
- **只記單堂分數**——排行榜效果大打折扣

## Worked Example
仙女老師「唱歌負增強」三段操作：
1. 預演：第一次統計後「啊，下課了！忘了留時間唱歌，這次先不算」——最後一名鬆一口氣，規則已深植人心
2. 預告：之後每堂「倒數 20 分鐘」提醒一次、「倒數 10 分鐘」再提醒——搶答越來越激烈
3. 說到做到：第三堂下課前五分鐘停止上課、全組上台各唱四句（自選曲）、「要等每個人都唱完才下課」——溫柔而堅定
→ 下一堂「超認真，因為他們也想看別組唱歌的尷尬模樣」

## Key Takeaways
1. 別再糾結內外動機之爭——2014 綜述已終結辯論：整合使用
2. 點數：連結重點、只加不扣、方便即時
3. 獎勵：學生想要的才有效；前三名有獎；開場展示＋導回學習
4. 排行榜：定時更新總分、閉眼投票、只公布前幾名、重點激勵
5. SDT 三原則是外在轉內在的轉換器
