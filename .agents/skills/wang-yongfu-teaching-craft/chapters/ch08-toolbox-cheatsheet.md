# 第 8 章：後記與核心工具速查表（教學的技術）

## Core Idea
全書技術的總收束：一張教學法全景對照表、四個核心架構（ADDIE／ARCS／PESOS／PBL）、一份課前 30 分鐘檢核清單——技術的背後是「尊重學員的時間與生命，用最短時間帶來最大改變」。

## Frameworks Introduced
- **教學法全景對照表**（選法速查）：

| 教學法 | 適用情境 | 關鍵步驟 | 注意事項 |
|---|---|---|---|
| 講述法 | 知識觀念、理論、故事 | 故事鋪陳、時間錨點、大字流 | 忌長篇大論，需搭配提問案例 |
| 問答法 | 破冰、引導思考 | 提問→Cue 人→重述→讚美→洞見 | 不喊 3-2-1，安全氛圍＋獎勵 |
| 小組討論法 | 複雜問題、痛點盤點 | 出題→大壁報紙→限時→發表→總結 | 忌無紙聊天；說得越少學得越好 |
| 演練法 PESOS | 技能、話術、標準動作 | P 準備→E 說明→S 示範→O 實作→S 指導 | 務必先示範；勿中途打斷 |
| 三明治回饋法 | 演練講評 | 優點→改進→優點 | 避開「但是」；具體指出行為 |
| 影片教學法 | 示範對照、感性激勵 | 提示重點→播放（3–5 分）→討論→歸納 | 內嵌自動播放，非電影欣賞會 |
| 個案討論法 | 決策模擬、兩難 | 情境→發資料→推論→公布真實解答 | 忍住不先破梗 |
| 大場互動法 | 100–400 人 | 站立分組（3–4 人）→選組長→選排連看 | 忌個人搶答 |
| 翻轉企業教學 | 基礎通識、產品簡介 | 課前任務→課堂演練驗收→回饋 | 把時間留給實戰 |

- **四大核心架構速記**：
  - ADDIE：Analysis→Design→Development→Implementation→Evaluation
  - ARCS 激發動機四要素：Attention 注意→Relevance 相關→Confidence 信心→Satisfaction 滿足
  - PESOS：Preparation→Explanation→Show→Operation→Supervise
  - PBL：Points 積分＋Benefits 獎勵＋Leaderboards 即時安全排行榜

## Key Concepts
- **技術可複製，熱情與修練搶不走**——作者公開壓箱寶的底氣
- **理論底蘊**：認知心理學、成人學習理論（Andragogy）、行為學派、建構主義、社會學習論（班杜拉）共同支撐這些技術
- **給教學者的三句話**：不害怕不完美（冷場是常態，挑戰是禮物）；以「學員學到什麼」為唯一度量；持續刻意練習（一次練一個技巧）

## Mental Models
- 把這張對照表當「處方箋」：先診斷（目標類型×現場條件），再開教學法
- ARCS 是檢驗動機設計的四問：有抓住注意嗎？跟他有關嗎？他有信心嗎？他有滿足嗎？

## Anti-patterns
- 為用方法而用方法——所有選擇以學習成效為準
- 追求講得天花亂墜而非學員做出來

## Worked Example
上課前 30 分鐘職業講師檢核清單：
- [ ] 設備與電源：自備筆電、外接喇叭、簡報筆（含備用電池）、充電線與轉接頭
- [ ] 音訊視訊：投影解析度、字型、內嵌影片播放、聲音輸出無雜訊
- [ ] 教室氛圍：提早 20–30 分鐘播放無版權純輕音樂
- [ ] 教具就位：白報紙、多色粗筆、計時器、計分板／籌碼、前三名獎品
- [ ] 時間校準：對齊教室時鐘
- [ ] HR 對齊：80% 到齊開場原則、請 HR 宣導關閉筆電

## Key Takeaways
1. 對照表選法、四架構設計、清單備戰——三件工具涵蓋全書
2. ARCS 補足了 PBL 之外的動機檢驗視角
3. 一次練一個技巧：今天問答、明天小組討論、後天三明治回饋
4. 所有技術的唯一出發點：尊重學員的時間與生命
