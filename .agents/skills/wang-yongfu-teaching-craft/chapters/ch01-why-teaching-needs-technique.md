# 第 1 章：關於教學這件事（教學的技術）

## Core Idea
教學不是藝術天賦，而是可拆解、可複製、可學習的「技術」。老師的價值不在讓學生「知道」，而在讓學生「得到」並當場「做到」。

## Frameworks Introduced
- **學習的三個層次：知道 → 得到 → 做到**
  - 知道：知識的單向接收（看書、Google、線上課都能取代）
  - 得到：經老師經驗轉化、學生真正理解並能應用
  - 做到：課堂現場演練、老師立即修正、行為真正改變——職業講師的終極目標
  - 使用時機：設計任何課程前，先問「這堂課要讓學生停在哪一層？」
- **教學的三個基本問題**
  - 教學經驗（老師的問題）：從「自己會」到「教別人會」距離遙遠
  - 學習態度（學生的問題）：企業學員視上課為義務，80% 以上初始態度中性或防衛
  - 環境干擾（手機的問題）：頭號敵人，與老師搶奪注意力，老師幾乎必輸
- **什麼是「正常」的學員**：九點只到一半、往後坐角落、不在乎講者是誰——面對對抗性學員是講師的日常，不是例外
- **誰需要教學的技術**：三種人——公司主管／資深員工（被指派授課）、學校老師、職業／業餘講師

## Key Concepts
- **職業講師**：以企業內訓為業、每堂課都是淘汰賽（滿意度 4.5 分是及格線，4.85 以上才有下次）
- **教學等於講述？**：講述只是知識轉述，網路可取代；實體課的價值必須超越聽講
- **佛系教學法**：作者明確否定的態度——「佛渡有緣人」「我盡力了」是不負責任的藉口

## Mental Models
- 把「台下學員不投入」視為**常態與起點**，把「誘發參與」視為教學的核心挑戰，而非抱怨學生素質
- 用「大師都用講述法」的思想實驗檢驗：換人照稿唸效果立即崩壞——大師的講述靠的是名聲帶動的動機，不是講述法本身
- 身為老師就沒有挑選戰場的權利：站在講台上，就必須完成有效果的教學

## Anti-patterns
- **佛渡有緣人心態**：把不投入歸咎學生，放棄教學責任——福哥名言「絕對沒有佛渡有緣人這回事，老師要為自己的教學負起全責」
- **把教學等同講述**：單向轉述在網路時代價值極低
- **自我安慰三連**：「這課不好教」「學生沒天分」「我不夠有名」——真正的心態是「一定有更好的教學方法，只是我還不知道」

## Worked Example
「正常企業學員」三問（換位思考測驗）：
1. 上課時間到、學員到場狀況？→ B：只到了一半（上課對講師是任務、對學員是義務）
2. 學員入座的位置？→ B：往後坐、找隱蔽角落（與認識的人坐，滑手機吃早餐）
3. 台下知道講者是誰嗎？→ B：不在乎（即使十年萬小時的知名講師，學員想的仍是「這跟我有什麼關係？」）

## Key Takeaways
1. 教學是技術：可拆解、可傳授、可複製；練到極致才成藝術
2. 評估自己課程的層次：停在「知道」的課可被任何媒介取代
3. 學員的冷漠是常態——先用 1-3 章的開場技術調整溫度，再談教學法
4. 目標口號：「老師說得越少，學生學得越好！」
5. 有效就是好的：不管什麼方法，學習成效是唯一度量
