# 第 5 章：遊戲化翻轉課堂——PBL 三元素（教學的技術）

## Core Idea
遊戲化＝在非遊戲環境應用遊戲核心元素以強化參與動機。核心是 PBL：積分（Points）、獎勵（Benefits）、排行榜（Leaderboards）——遊戲化不等於遊戲，更不等於團康。

## Frameworks Introduced
- **福哥版 PBL**（原版為 Points／Badges／Leaderboards，實測徽章無效，改為）：
  - **P 積分**：每個回答、參與、表現都計分
    - 原則：有表現就有分（不管對錯）、只加分不扣分、加分標準公平、差異式計分（越難分數越高：搶答 1000–5000／上台次序 5000→1000／大型演練 20000–50000）
    - 計分方式：組長計分、助理計分、輪流計分、撲克牌／籌碼／假鈔實體計分
  - **B 獎勵**：給團體不給個人（個人獎勵次數受限、對象稀少、易受同儕壓力）；前三名都給獎且獎品有區隔（第一名疊疊樂、第二名七巧板、第三名金莎）；獎品可無形（晉升、認證）或有形
  - **L 排行榜**三大操作原則：
    1. 即時反應、即時公布——每節下課更新總分貼在教室後面，上課前表揚「暫時領先」
    2. 兼顧競爭與面子——閉眼投票（投三票：自己＋兩票他組）；只公布前三名，「課程中從來沒有最後一名」
    3. 平衡機會且公平——後段演練配分加重，營造「人人有希望，個個沒把握」
- **「遊戲化不是團康化」**：不需要隊名、隊呼、到齊喊口號、大聲問安——科技業工程師沉默而認真地為團隊搶分，才是真動力

## Key Concepts
- **獎勵是參與的理由，不是目的**：副總為一盒積木動員全組——在乎的是榮譽，獎品只是名正言順的理由
- **計分是承諾**：下課時間各組會到計分板前關心戰況——所以公平計分很重要
- **安全環境**：不公布後段名次＝把面子留給表現不佳者，大家反而更敢投入之後的競賽

## Mental Models
- 把 PBL 想成引擎三缸：點數即時點火、排行榜持續推進、獎勵最終兌現——缺一缸動力就衰減
- 外在動機是火種：先點燃參與，再轉化為學習的內在樂趣

## Anti-patterns
- **徽章制**：「白金好學生」「鑽石騎士」等虛擬徽章——研究證實與表現無顯著影響，企業學員根本不想要
- **最後才統計公布排名**：過程中不知名次，激勵作用歸零
- **只獎勵第一名**：差距拉開後落後組直接放棄
- **最後一場分數暴增（如 100 萬分）**：「前面都玩假的？」——配分要平衡
- **團康式炒作**：隊呼大喊只有十秒效果，不配合時極度尷尬

## Worked Example
翻盤配分計算：最後一堂課前累計——第一組 80000、第二組 72000、第三組 68000、第四組 60000、第五組 53000。最後一場比賽配分 50000／40000／30000／20000／10000。
- 落後組奪冠：53000 + 50000 = 103000 → 超越原領先組
- 領先組只拿第四：80000 + 20000 = 100000 → 可能跌至第二至四名
→ 落後組有翻盤希望、領先組不敢鬆懈，動力維持到最後一節。

## Key Takeaways
1. 課程遊戲化的重點不是好玩，而是學習——PBL 是手段
2. 分數只加不扣；要「懲罰」就獎勵其他組
3. 排行榜每節更新累計總分，只公布前幾名
4. 獎勵給團體、前三名有獎、開場就展示
5. 學員爭的從來不是獎品，是團隊榮譽
