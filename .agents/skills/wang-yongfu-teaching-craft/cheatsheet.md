# 決策速查表（Cheatsheet）

福哥會怎麼判斷、怎麼選擇——決策規則優先，速查速用。

## 教學法選擇決策樹
```
教學目標是什麼（ASK）？
├─ 知識（K）→ 講述（故事化）＋問答／單選複選＋搶答複習
├─ 技巧（S）→ PESOS 演練（必含示範）＋競賽＋三明治回饋
└─ 態度（A）→ 情境故事＋兩難抉擇＋心得寫作驗收
現場條件？
├─ 動機強／講者魅力高 → 純講述即可
├─ 一般企業內訓 → 開場五件事＋小組討論為引擎＋PBL
└─ 100–400 人大場 → 站著分組 3–4 人＋全員參與型互動（忌搶答）
```

## 分組決策
| 情境 | 每組人數 | 分法 |
|---|---|---|
| 教室型 20–50 人 | 4–6 人 | 老師點數字隨機打散 |
| 大場演講 30–300 人 | 3–4 人 | 站起來湊組坐下 |
| 學期課 | 依班級 | 自願組隊交名單（段考後重排） |
| 長輩班（60 歲↑） | 不分組 | 個人計分 |

## 配分原則（只加不扣）
- 問答搶答 1000–5000｜上台次序 5000→1000｜演練競賽 20000→5000
- 越難越高分，但最後一場不得暴增（防「前面玩假的」）
- 翻盤檢驗：末場配分 ≈ 前後名次差距 × 1.5–2 →「人人有希望，個個沒把握」
- 懲罰情境 → 獎勵其他組（手機響＝他組各 +5000）

## 獎勵決策
- 學生想要的才是好獎勵：企業→書／玩具／簽名書；長輩→米等生活必需品；青少年→負增強（免唱歌、免報告）
- 前三名都有獎且獎品有區隔；開場就展示＋導回學習（「上課不是為了獎品」）
- 不人人有獎（消除競爭）；獎品給團體不給個人

## 高頻情境 → 對策
| 徵兆 | 診斷 | 對策 |
|---|---|---|
| 學員微笑點頭但叫不出上張投影片 | 螢幕保護程式 | 插入互動＋計分，別再加講述 |
| 遊戲化了仍沒人舉手 | 半數是缺團隊機制 | 補分組＋無風險（有答就有分） |
| 互動與課程無關（猜電影） | 教學歸教學遊戲歸遊戲 | 改成課程內容的選擇／判斷題 |
| 落後組放棄 | 配比失衡／只獎第一名 | 末場高分＋前三名有獎＋重點激勵 |
| 有人嘲笑答錯者 | 無風險被破壞 | 「肯回答就是勇氣，答錯加 100；嘲笑者扣 100 但道歉可免」 |
| 第二堂開始姍姍來遲 | 懲罰準時者循環 | 下課前提醒＋到齊加分＋老師以身作則 |
| 手機響了 | — | 不罰當事人，其他組 +5000，全場大笑繼續 |
| 長官在場不敢互動 | 想像出來的限制 | 照樣分組——院長也會站起來組小組 |
| 接在枯燥課後第二棒 | 學員已耗盡 | 緩慢加溫：自介→故事→目標→再分組 |
| 現場沒人答錯 | 題目太簡單 | 下次加難——引導犯錯才是學習點 |

## 回饋字句替換
| ❌ 避免 | ✅ 改用 |
|---|---|
| 「但是…」 | 「如果可以的話…」「下一次有機會…」 |
| 「這個答案不對」 | 「接近了，還有沒有別的答案？」 |
| 只講缺點 | 優點→改進→優點 |
| 「為什麼大家都還沒到」 | 什麼都別說（不懲罰準時者） |

## 開課前 60 秒最終檢查
設備自帶（筆電/喇叭/簡報器/時鐘）？時鐘校準？音樂播放中？獎品三份就位？計分載體就位？HR 對齊（80% 開場、宣布關筆電）？

## 黃金口訣
1. 老師說得越少，學生學得越好
2. 知道→得到→做到
3. 遊戲為課程服務，不是為了好玩
4. 遊戲化不是團康化
5. 課程中從來沒有最後一名
6. 獎勵是參與的理由，榮譽才是動力
7. 外在動機是火種，內在動機是柴火
