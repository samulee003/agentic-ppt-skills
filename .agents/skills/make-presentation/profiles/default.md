# Profile: default

## Language

- On-screen copy uses the audience's written language. Speaker notes use the
  language the presenter will speak, in a spoken register.
- One language per surface: no stray untranslated words on slides or in notes.

## Product grill

- Deck type: ask; recommend from the source and audience (`../references/deck-types.md`).
- Theme: `editorial-minimal` unless the source, brand, or deck type points elsewhere.

## Story architecture

- Use the default structure for the deck type.

## Stage grill

- Talks over 30 minutes need an attention reset (question, poll, pair
  discussion, demo, or short pause) at least every 15–20 minutes.
