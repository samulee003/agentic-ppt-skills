# Prototype set

Build these representative pages in the real slide source:

- opening / hook
- thesis (`hero`)
- representative evidence (a `data` slide if the deck has numbers)
- the most difficult or dense page
- one `interaction` page if the deck type or profile calls for it
- ending / call to action

Then review them live in the chosen engine's review surface (see `adapters/<engine>/prototype.md`).
