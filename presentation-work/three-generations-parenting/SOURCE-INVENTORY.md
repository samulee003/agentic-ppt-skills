# Source Inventory: 三代共贏的教養智慧

## 1. 講座基本資料與主辦需求

- **主題**：《三代共贏的教養智慧》
- **活動形式**：1.5 小時（90 分鐘）實體/線上家庭親職專題講座
- **主辦單位目標**：
  1. 探討隔代教養中的觀念差異與協調技巧。
  2. 促進祖輩與父母間的溝通理解，學習建立一致教養原則，發揮各自優勢，共同為孩子營造穩定、和諧的成長環境。
- **目標受眾**：澳門雙職家庭父母為主，預期有部分祖父母（爺爺、奶奶、外公、外婆）同行參加。

## 2. 澳門家庭在地背景與現實素材盤點 (Material-First)

| 素材維度 | 具體事實與情境 (Facts & Scenarios) | 講座應用點與轉化 |
| :--- | :--- | :--- |
| **雙職輪班現狀** | 澳門博彩、酒店餐飲、公職及服務業比例高，雙職家庭日間照顧長輩參與率超過 60%。 | 開場即建立「長輩是恩人與定海神針」的感恩基調，徹底卸除長輩被說教的防禦心理。 |
| **核心觀念衝突** | 1. **飲食/零食**：長輩怕孫餓著、餵食 vs 父母定時定量、吃蔬菜。<br>2. **3C 螢幕**：長輩手機安撫 vs 父母護眼與自控力培養。<br>3. **生活自理**：長輩代勞穿鞋穿衣 vs 父母培養獨立性。 | 透過「事件還原法」還原具體生活場景，避免抽象對立。 |
| **孩子心理機制** | 孩子在三代不同標準下學會「行為套利」（爸媽說不行就轉身找長輩），導致情緒與規則崩塌。 | 揭示「權力夾縫」真相，讓三代人意識到拆台的最大受害者是孩子。 |
| **溝通痛點** | 父母工作疲憊下班，當場看見違規而脫口指責；長輩感到委屈（「辛苦一整天還被嫌棄」）。 | 提供「5 秒接棒話術」與「4 步溝通飛輪」，落實「當面補台、私下協商」。 |
